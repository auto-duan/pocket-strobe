# 微光 · Pocket Strobe

纯前端 Vite + React + TypeScript + Tailwind CSS 4（官方 Vite 插件） 手机频闪页面。没有后端，不显示、录制或上传相机画面，不加载外部字体或分析脚本。

在线使用：https://auto-duan.github.io/pocket-strobe/

## 本地运行

需要现代 Node.js（建议 Node 22.12+）。

```sh
npm ci
npm run dev -- --host
```

- 屏幕与后置 LED 共用唯一目标频率：0.1–999 Hz，默认 15 Hz，共用预设 12 / 15 / 20 / 24 / 30 Hz；切换模式原样保留输入（包括 999.0），没有模式专属限幅。
- 无滑条，使用带移动端小数键盘的数字文本输入与预设；运行中锁定设置。输入草稿是唯一配置来源，不存在隐藏旧值。允许编辑中清空与末尾小数点（12. 按 12 解释且保留原文）；失焦及启动时验证。严格拒绝空值、零、负数、非有限值、超范围、超过一位小数、科学计数法、空格、正号与省略整数位的 .1；不静默取整或限幅，显示行内错误并禁止启动。
- 点击开始即可启动，无风险确认勾选或弹窗；默认 15 Hz，始终手动启动、不自动启动。
- 运行时固定边到边覆盖整个网页视口，隐藏设置、标题与警告，仅右上角保留低调紧凑的停止按钮（至少 44px 触控目标，自动聚焦、键盘可操作）。轻触任意位置、Esc、页面隐藏、pagehide 或组件卸载均停止。
- 可选系统全屏与 Wake Lock；不支持或拒绝时降级，不影响停止。仅浏览器系统全屏成功才可能隐藏浏览器栏；网页视口覆盖不代表隐藏浏览器栏。

## 手机手电筒注意

手机通过局域网 HTTP 地址访问通常不能使用相机；请自行配置可信 HTTPS 开发环境。localhost 的安全上下文豁免仅针对设备本机，不代表手机访问电脑 IP 也可用。公开站点使用 GitHub Pages HTTPS 托管；相机权限与 LED 支持仍取决于设备和浏览器。

仅在点击开始后申请后置相机（environment exact），不申请麦克风。检测 getCapabilities().torch。Android Chrome + 支持 LED 的后置相机通常更合适；**iOS 浏览器通常不支持 torch 控制**，请使用屏幕模式。权限拒绝、后置相机缺失、相机占用、能力不支持均给出说明。停止期间未完成的权限请求无法被浏览器 API 取消，但其迟到媒体流会关闭灯并释放全部轨道，绝不重新启动。

LED applyConstraints 串行等待；停止立即取消调度并将关灯排在当前写操作之后，最后停止轨道。浏览器冻结、硬件故障或驱动调用迟迟不返回时，网页无法保证瞬时关灯；必要时关闭页面或从系统关闭相机/手电筒。

## 安全与精度

**闪光可能引发光敏性癫痫、眩晕或其他不适，即使没有既往病史。** 有相关病史请勿使用；避免照射他人、儿童、驾驶场景；任何不适立即停止。低频并不代表无风险。系统减少动态效果偏好会显示额外提醒，页面没有装饰性动画。

Hz 表示目标每秒闪光次数，不是显示 FPS，也不是实测值。屏幕使用 requestAnimationFrame 和单调时间相位，每显示帧最多更新一次，直接写入输出 DOM，避免 React 高频重渲染；跳过错失的边沿，不追赶补发。60 Hz 屏幕理想交替上限 30 Hz；亮暗最短各一帧（约 16.7 ms），15 Hz 理想亮暗各两帧，20 / 24 Hz 等存在量化和混叠，不能保证精确定格。

50% 为目标占空比，不提供虚假的亚帧短脉冲设置。定格清晰度更适合短脉冲专用频闪灯；屏幕只能探索暗处运动物体的定格/慢动作错觉，亮度、物体速度与同步都会影响效果。LED 与屏幕都可设置至 999 Hz，但这只是目标，不是实测或保证值。LED 串行等待每次写入完成，下一次至少等待 16 ms（最多约 63 次状态写入/秒，完整亮暗周期还需两次写入），慢硬件进一步降低速率；不构造高频计时忙循环、不堆积脉冲。定时器、刷新率、LED 驱动、设备负载和省电策略均影响实际频率。慢写入不重叠、不追赶补发脉冲。非精密测量、医疗或求救工具，持续使用会耗电、发热；勿长时间运行。

## 验证

```sh
npm run build
npm run typecheck
npm test
node scripts/smoke.mjs
```

浏览器 smoke 使用已安装 Google Chrome，自动启动/关闭仅限 127.0.0.1 的临时 Vite 服务；启动操作使用强制黑色覆盖样式，**不产生实际可见频闪**。截图保存未启动页面与强制黑色运行覆盖层至 verification/。硬件 LED、真实手机权限、实际频率、系统全屏和常亮需真机验证，自动模拟通过不等于硬件通过。
